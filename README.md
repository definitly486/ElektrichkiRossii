# Электрички России

Стартовый Android-проект на Kotlin + Jetpack Compose.

## Что уже есть
- Главный экран в стиле современных приложений расписаний.
- Выбор даты поездки.
- Поле для API-ключа Яндекс.Расписаний, сохранение ключа локально.
- Клиент поиска электричек через `v3.0/search/`.
- Карточки найденных рейсов.

## Важное ограничение этой стартовой версии
Поиск пока принимает коды станций API, но экран выбора станций по названию и локальный индекс справочника ещё не реализованы. Поэтому приложение пока не является законченным пользовательским продуктом. Следующий обязательный этап — загрузка/индексация `stations_list`, автодополнение станций и получение полного маршрута через `/thread/`.

## Получение ключа
Получите ключ в кабинете разработчика Яндекс.Расписаний:
https://yandex.ru/dev/rasp/raspapi

Ключ вводится в приложении через кнопку API. Не публикуйте его в GitHub.

## Сборка
Откройте папку в Android Studio (JDK 17, Android SDK 36) и выполните:
`gradle :app:assembleDebug`

Для сборки через GitHub Actions можно добавить workflow после проверки проекта в вашей среде.
